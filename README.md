# 🎵 Spotify Downloader Plugin for WhatsApp Bot

Plugin ini memungkinkan bot WhatsApp berbasis Baileys untuk **mendownload lagu dari Spotify** langsung ke format MP3.

---

## ✨ Fitur

- Download lagu Spotify hanya dengan link track.
- Hasil dikirim sebagai **audio MP3** ke chat.
- **CookieJar otomatis** – tidak perlu update cookie manual.
- **Auto-retry & refresh CSRF token** jika session habis.
- Mendukung **Owner & Premium** – bebas limit harian.
- Tidak perlu akun Spotify Premium.

---

## 📦 Persyaratan

- Node.js **16+**
- Bot WhatsApp menggunakan **@whiskeysockets/baileys**
- Mendukung **CommonJS (CJS)** dan **ES Module (ESM)**
